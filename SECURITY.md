# Segurança

Não registre senhas, tokens, URLs de banco ou dados pessoais no repositório, em issues ou em logs. Configure segredos somente no ambiente local ignorado pelo Git e no gerenciador de variáveis do serviço de hospedagem.

O painel administrativo usa sessão curta armazenada apenas na aba do navegador. A liberação para primeiro cadastro emite um código temporário de uso único. Relatórios e listas de associados exigem autenticação administrativa.

Se uma credencial for exposta, revogue ou rotacione a credencial antes de remover o valor do histórico. A retirada do texto do Git não invalida uma credencial que já foi copiada.

Relate uma vulnerabilidade diretamente ao responsável técnico da AAFAB, sem incluir dados pessoais reais na demonstração.
